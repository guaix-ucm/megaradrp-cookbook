options:
  -h, --help            show this help message and exit
  -s, --spectrum RSS FILE
                        RSS input file
  -f, --method FITTING FUNCTION (0,1,2)
                        Fitting function (0=gauss_hermite, 1=gauss, 2=double_gauss)
  -S, --limsnr MINIMUM S/N
                        Mininum Signal-to-noise ratio in each spaxel
  -w, --ctwl LINE CENTRAL WAVELENGTH
                        Central rest-frame wavelength for line (AA)
  -k, --use-peak        Use peak first guess on central wavelength
  -LW1, --lcut1 LOWER WAVELENGTH - LINE
                        Lower rest-frame wavelength for line (AA)
  -LW2, --lcut2 UPPER WAVELENGTH - LINE
                        Upper rest-frame wavelength for line (AA)
  -CW1, --ccut1 LOWER WAVELENGTH - CONT
                        Lower rest-frame wavelength for cont. (AA)
  -CW2, --ccut2 UPPER WAVELENGTH - CONT
                        Upper rest-frame wavelength for cont. (AA)
  -ECW1, --eccut1 EXCLUDE FROM CONT. (LOWER WAVELENGTH)
                        Lower rest-frame wavelength of range to exclude for cont. (AA)
  -ECW2, --eccut2 EXCLUDE FROM CONT. (UPPER WAVELENGTH)
                        Upper rest-frame wavelength of range to exclude for cont. (AA)
  -PW1, --pcut1 LOWER WAVELENGTH - PLOT
                        Lower (observed) wavelength for plot (AA)
  -PW2, --pcut2 UPPER WAVELENGTH - PLOT
                        Upper (observed) wavelength for plot (AA)
  -S2, --scale-amp2 SCALE FACTOR FOR AMP2
                        Scale factor for amplitude 2
  -z, --redshift REDSHIFT
                        Redshift for target and catalog lines
  -o, --output OUTPUT-PDF
                        Output PDF
  -v, --verbose         Verbose mode for fitting results?
  -O, --output-rss OUTPUT RSS FILE
                        Output RSS file
  -of, --output-fibers OUTPUT FIBERS LIST
                        Output list of fibers above minimum Signal-to-noise ratio
  -a, --absorption      Are you analyzing an absorption feature?
  -i, --index           Measuring spectral indices?
  -H, --heliocentric    Apply heliocentric correction to velocities?
  -co, --coord TARGET COORDINATES
                        Coordinates ("01:58:00 +65:43:05")
  -tm, --time TIME      Time in format "2019-09-24T02:23:22.19"
